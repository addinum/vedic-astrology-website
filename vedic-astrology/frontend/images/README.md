# Images needed for this template

Add your own images with these exact filenames so the site renders correctly:

- favicon.png (48x48 or 64x64) — site icon
- og-cover.jpg (1200x630) — social share preview image
- hero-pandit.jpg (landscape, ~1000x800) — homepage hero photo
- pandit-portrait.jpg (portrait, ~800x1000) — about section photo
- blog-placeholder.jpg (landscape, ~800x500) — fallback cover for articles without an image

You can source temple/puja-appropriate stock photography or use your own professional photos.
Gallery and Panchang images/PDFs are uploaded directly through the Admin Dashboard and stored under
backend/uploads/ — no manual file placement needed for those.
